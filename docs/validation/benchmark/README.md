# Benchmark Data

This directory stores the actual files a validation run produces and
compares — see [`../VALIDATION.md`](../VALIDATION.md) for the full
process and [`../../../tools/validation/README.md`](../../../tools/validation/README.md)
for the comparison tool itself. Nothing in this repository generates or
invents the contents of these folders; they are populated by hand (or by
a release job) from a real reference source and a real Slipstream run.

```
benchmark/
├── README.md      # this file
├── reference/     # trusted reference dataset CSV(s) — never generated by Slipstream
├── slipstream/    # Slipstream's own exported results CSV(s) for the same case
└── plots/         # generated comparison PNGs (cl_/cd_/ld_comparison.png)
```

## `reference/`

Drop the reference dataset CSV(s) here. Expected columns (minimum):

```
AOA_deg, Velocity_m_s, CL, CD
```

Source must be independent of Slipstream — published wind-tunnel data, an
established CFD benchmark case, or a separately-validated solver run.
Cite the source in `docs/validation/VALIDATION.md` §9.

## `slipstream/`

Drop Slipstream's own exported results here, in the same column shape.
Produced directly by the existing ledger CLI — no new export format:

```bash
python main.py export-study <study_name> --out docs/validation/benchmark/slipstream/<study_name>.csv
```

## `plots/`

Generated, not hand-authored — see `tools/validation/plots.py`. Re-running
the comparison tool with `--plots` overwrites these with the current
reference/Slipstream pair.
